# ZhiZhang（知账）— 个人财务智能助手

> 一个由大语言模型驱动的个人财务 AI Agent：聚合微信 / 支付宝 / 银行多渠道账单，自动完成收支分类、月度分析、现金流预测，并通过自然语言对话提供财务问答与建议。

## ✨ 项目亮点

- **LLM Agent + Function Calling**：自研 Agent 循环，LLM 根据用户问题自主决策调用 9 种财务分析/执行工具，基于真实数据回答，绝不编造
- **多渠道账单聚合解析**：微信、支付宝、银行三源账单统一为标准化交易模型，自动识别并过滤跨渠道重复记录（如银行侧财付通/支付宝快捷支付）
- **智能自动分类**：商户规则引擎 + 支付宝自带分类映射 + LLM 批量分类建议，识别置信度分级（high / medium / pending）
- **未来现金流预测**：基于历史趋势 + 固定收支 + 负债分期，生成未来 12 个月逐月流水表与期末余额预警
- **双端交互**：Web 仪表盘（可视化图表）+ 终端 CLI（Rich 表格）两种使用方式
- **完整闭环**：导入 → 解析 → 去重 → 分类 → 分析 → 预测 → 提醒，覆盖个人财务管理的全流程

## 🧠 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                         交互层                                │
│    Web 仪表盘 (Flask + Chart.js)     CLI 终端 (Rich)          │
└────────────────────────────┬────────────────────────────────┘
                             │ REST API / 直接调用
┌────────────────────────────▼────────────────────────────────┐
│                      Agent 核心层 (agent.py)                 │
│   LLM 对话循环 + 工具调度（OpenAI SDK，兼容 DeepSeek 等）      │
│   「财务助手」系统提示词 + 最多 5 轮 Function Calling 循环      │
└────────────────────────────┬────────────────────────────────┘
                             │ TOOL_SCHEMAS（9 个工具）
┌────────────────────────────▼────────────────────────────────┐
│                      工具层 (tools.py)                       │
│  查询：月度汇总/分类占比/交易查询/消费趋势/商户排行/现金流预测   │
│  执行：批量分类/批量打标签（写库 + 规则自学习）                 │
└────────────────────────────┬────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────┐
│                      分析层 (analyzer.py)                    │
│  纯函数式统计：去重过滤 → 汇总 → 分类 → 趋势 → 预测            │
└────────────────────────────┬────────────────────────────────┘
                             │
┌───────────────┬────────────┴──────────────┬─────────────────┐
│  数据加载层    │      持久化层              │   文档解析        │
│ (data_loader) │  (SQLite: database.py)    │  (MinerU)        │
│ 微信/支付宝/银行 │ 交易/账户/负债/储蓄/理财   │ PDF银行流水       │
│ 统一 Transaction │ 分类规则/标签/分期/提醒    │ Excel财务计划表    │
└───────────────┴───────────────────────────┴─────────────────┘
```

**设计要点**

- **分层解耦**：数据加载 / 分析 / 工具 / Agent / Web 各层职责单一，分析层为纯函数，便于单元测试
- **Agent 与数据分离**：LLM 只负责决策工具调用，所有数据计算由确定性代码完成，回答可追溯、可复现
- **规则 + LLM 双引擎分类**：确定性规则兜底，LLM 处理长尾商户，兼顾准确率与覆盖率
- **写入工具带确认机制**：批量分类/打标前先查询确认商户与笔数，避免误操作

## 🛠️ 技术栈

| 类别 | 技术 |
| --- | --- |
| 语言 | Python 3.11+ |
| AI Agent | OpenAI SDK（Function Calling，兼容 DeepSeek / Qwen / GLM 等国内 API） |

| 数据源 | 微信支付、支付宝、兴业银行账单（TSV / PDF / XLSX） |

## ⚡ 快速开始

```bash
# 1. 克隆项目
git clone https://github.com/<your-name>/ZhiZhang.git
cd ZhiZhang

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置 LLM（可选，不配置则仅支持斜杠命令）
# 方式一：环境变量
export DEEPSEEK_API_KEY="sk-xxx"        # Windows: $env:DEEPSEEK_API_KEY="sk-xxx"
# 方式二：编辑 agent/config.json 中的 llm.api_key

# 4. 启动 Web 应用
python agent/web/app.py
# 打开 http://127.0.0.1:5000

# 5. 或使用 CLI
python agent/main.py
```
